# List / listicle outline

**Length:** 8-15 minutes
**Goal:** Deliver N items with enough depth that each is useful

## 0:00 - 0:15 - Hook

[Set up the list. "N [things] for [audience] to [outcome]." Be specific. Vague lists ("5 amazing tips") underperform specific ones ("5 keyboard shortcuts that save 30 minutes a day").]

## 0:15 - 0:45 - Promise + framing

- Confirm the list count
- State the criteria you used to pick the items
- Tease the most surprising or counterintuitive item

## 0:45 - 1:00 - Disclosure (if applicable)

[If any items are affiliate-linked or sponsored: disclose now, before any items.]

## 1:00 - end of body - Items

For each item:

### Item N: [Concrete name]

- What it is (brief)
- Why it earned a spot on this list
- Specific example or demonstration
- (Optional) When you'd use this vs not

[Repeat for each item. Vary the depth, not every item needs the same word count. The most interesting item gets the most time.]

## Numbering convention

Two viable approaches:

- **Top-down (N to 1):** "starting with #5..." Builds tension toward the best.
- **Bottom-up (1 to N):** "starting with #1..." Front-loads the strongest.

Top-down keeps watch time longer (people stay for the climax). Bottom-up loses retention but builds trust faster (you're not making people wait for the good stuff).

## Notes for list format

- **The list count must match what you delivered.** "5 things" with 4 things is a credibility hit.
- **No filler items.** If item #4 is weak, replace it or cut to a 4-item list.
- **Use chapters.** Each item gets a chapter marker. Viewers love jumping.
- **Don't bury the strongest item.** If #5 is amazing, mention it in the hook so people stay.
