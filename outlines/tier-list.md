## Notes for tier list format

- **Use a visible tier-list graphic.** Viewers want to see the list build up.
- **Never put EVERYTHING in S tier.** That's not a ranking, that's a love letter.
- **Defend controversial placements specifically.** "I know I'll get comments about [item] in [tier], here's why." Pre-empts pile-on.
- **Acknowledge category limits.** "I only ranked the X I've actually used." Stops "you forgot Y" comments.
- **Comparison is implicit.** Tier lists work because items are ranked relative to each other; absolute rankings are less interesting.
